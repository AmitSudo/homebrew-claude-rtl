# Homebrew Tap: claude-rtl

RTL (right-to-left) text support for Claude Desktop on macOS.

## Install

```bash
brew install AmitSudo/claude-rtl/claude-rtl
```

Then run:

```bash
claude-rtl install
```

## Usage

```bash
claude-rtl install    # Install/re-apply the RTL patch
claude-rtl uninstall  # Remove the patch and restore original
claude-rtl reapply    # Re-apply after manual update
claude-rtl revert     # Restore from backup
```
